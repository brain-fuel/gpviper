# GoForge Viper migration facade

`goforge.dev/gpviper` is a bounded compatibility facade for
`github.com/spf13/viper` v1.21.0
(`394040caccbdf5821fa6839386a35f0fb1b1ee9e`, MIT).

It supports the high-use default, file, environment, flag, override, alias,
lookup, and settings APIs while making the improved boundary explicit:
`Snapshot` is immutable, safe for lock-free concurrent reads, and retains the
winning source for every value.

The production implementation is authored in `viper.gp` and `reload.gp`.
Version-marked `*_gp.go` files are reproducibly generated by the Go+ compiler
pinned as a Go tool in `go.mod`:

```sh
go generate ./...
go tool goplus gen -check ./...
go test ./...
```

`Resolution[T]` is the exhaustive Go+ lookup surface:
`ResolvedValue(value, source)` retains provenance and `MissingResolution`
represents absence without a zero-value/boolean convention.

Effectful reload is separate: `ReloadStream` serializes loader attempts and
publishes ordered success/failure events containing owned snapshots. Reads
never trigger I/O and a failed reload cannot mutate the last good snapshot.

The supporting standard-library model lives in `std/config`: `Snapshot[s]`,
`Key[T,s]`, required-key evidence, and typed subset projection make schema
mixups unrepresentable in Go+ and preserve runtime guards for ordinary Go.

See `COMPATIBILITY.md`, `PERFORMANCE.md`, and the complete 192-declaration
`API_MANIFEST.csv`. The current facade implements all 192 declarations. That
closes the declaration inventory, not the release gate: exhaustive behavioral,
integration, fuzz, and paired-performance proof remains in progress.

The implementation is independently structured; no upstream implementation
source was copied. `UPSTREAM_LICENSE` preserves Viper's copyright and MIT
notice alongside GoForge's own `LICENSE`.

## Reproduce the inventory

```sh
upstream_root=$(go env GOMODCACHE)/github.com/spf13/viper@v1.21.0
go run ./internal/cmd/apimanifest "$upstream_root" API_MANIFEST.csv
```
